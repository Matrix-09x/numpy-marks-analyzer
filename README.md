# Student Marks Analyzer

A Python-based Student Marks Analyzer built using NumPy.
This project analyzes student marks and provides different types of performance insights and statistics.

---

## Features

1. Calculates percentage and grades for each student
2. Identifies the topper and lowest scoring student
3. Shows total failed students along with their names
4. Shows total distinction students along with their names
5. Calculates average marks of each subject
6. Identifies:

   * Subject with highest average
   * Subject with lowest average
   * Hardest and easiest subject
   * Topper of each subject
   * Student rankings
